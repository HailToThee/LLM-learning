# This repository is a learning script on Large language models(LLMs)
Initially, it is built based on the book *LLM from scratch*, the book that introduces the basic knowledge
of language models.

including the evolution history of word embedding, 
tokenization, Attention mechanism, Feed forward, and self-regression, all of which we can see in the folder GPT-2_llm_fro_scratch.

llama3_from_scratch is all about the implementation of llama.

The folder mllm includes the basic knowledge of MLLM, and some safety paper reviews.
